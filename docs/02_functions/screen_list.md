# 画面一覧

本システムで提供する全画面の一覧と詳細仕様を記載します。

## 画面分類

### 1. エンドユーザー向け画面

| 画面ID | 画面名 | パス | ファイル名 | 概要 |
|--------|--------|------|-----------|------|
| S001 | ホーム画面 | `/` | HomePage.vue | 地図表示と特典検索・経路案内のメイン画面 |

#### 1.2 ユーザー管理画面

| 画面ID | 画面名 | パス | ファイル名 | 概要 | 認証 |

### 2. 管理者向け画面

管理者アカウントでログイン後にアクセス可能な管理画面（ファイルは `pages/admin/` 配下）。全画面で認証（`Authorization: Bearer <token>`）と管理者権限（`ROLE_ADMIN`）が必須。未ログイン時は `/login?redirect=...`、管理者以外は `/` にリダイレクトされる。

| 画面ID | 画面名 | パス | ファイル名 | 概要 | 認証 |
|--------|--------|------|-----------|------|------|
| SA001 | 事業者管理画面 | `/admin/agencies` | AdminAgencyPage.vue | 交通事業者のCRUD管理・CSVインポート/エクスポート | 必須（管理者） |
| SA002 | 特典種別管理画面 | `/admin/benefit-categories` | AdminBenefitCategoryPage.vue | 特典カテゴリのCRUD管理・CSVインポート/エクスポート | 必須（管理者） |
| SA003 | 特典管理画面 | `/admin/benefits` | AdminBenefitPage.vue | 特典情報のCRUD管理・CSVインポート/エクスポート・座標一括取得・確認済み更新（最終確認日） | 必須（管理者） |
| SA004 | 特典条件管理画面 | `/admin/benefit-eligibilities` | AdminBenefitEligibilityPage.vue | 特典利用条件のCRUD管理・CSVインポート/エクスポート | 必須（管理者） |
| SA005 | コミュニティバス路線管理画面 | `/admin/community-buses` | AdminCommunityBusPage.vue | コミュニティバス路線のCRUD管理・CSVインポート/エクスポート | 必須（管理者） |
| SA006 | 運賃割引管理画面 | `/admin/fare-discounts` | AdminFareDiscountPage.vue | 運賃割引情報のCRUD管理・CSVインポート/エクスポート | 必須（管理者） |
| SA007 | 自治体管理画面 | `/admin/municipalities` | AdminMunicipalityPage.vue | 自治体情報のCRUD管理・CSVインポート/エクスポート | 必須（管理者） |
| SA008 | ユーザー管理画面 | `/admin/users` | AdminUsersPage.vue | ユーザーアカウントの参照・編集・削除・CSVエクスポート | 必須（管理者） |

**管理画面共通レイアウト**:
- `layouts/AdminLayout.vue` の左側にサイドバー（`AdminSidebar.vue`）を表示し、各管理画面へ遷移する
- サイドバーの並び順: 特典管理 → 特典条件管理 → 特典カテゴリ管理（SA002） → 自治体管理 → 事業者管理 → 運賃割引管理 → コミュニティバス路線管理 → ユーザー管理
- ヘッダーの「管理者画面」メニューからは特典管理（`/admin/benefits`）に遷移する
- CSVエクスポートは一覧テーブル（`AppDataTable`）に表示中のデータをCSVファイルとして出力する

## 画面別詳細仕様

### S001: ホーム画面（HomePage.vue）

**概要**: アプリケーションのメイン画面。地図表示と特典検索・経路案内機能を統合した中核画面。

**レイアウト構成**:
```
┌─────────────────────────────────────────────────────────┐
│           ヘッダー（ナビゲーション・ユーザーメニュー）         │
├─────────────────────────────────────────────────────────┤
│                                                         │
│                     地図エリア                           │
│                  （特典マーカー表示）                     │
│                                                         │
├─────────────────────────────────────────────────────────┤
│  サイドバー（ルート案内/利用できる特典/特典を探す タブ）     │
├─────────────────────────────────────────────────────────┤
│      サイドバー下部ボタン（問い合わせ・ライセンス情報）        │
└─────────────────────────────────────────────────────────┘
```

**主要コンポーネント**:
- ヘッダーナビゲーション（AppHeader）
- 地図表示エリア（MapLibre GL JS）
- ルート案内タブ（AppRouteGuidance・AppRouteResultList）
- 利用できる特典タブ（AppUsersBenefit）
- 特典を探すタブ（AppSearchBenefit）
- フィードバックモーダル（AppFeedbackModal）: サイドバー下部「問い合わせ」ボタン（`pi pi-envelope`）から起動
- ライセンス情報モーダル（AppLicenseModal）: サイドバー下部「ライセンス情報」ボタン（`pi pi-info-circle`）から起動

**画面要素**:
- **地図**: インタラクティブマップ、ズーム・パン操作
- **マーカー**: 特典施設のピン表示
- **サイドバー**: ルート案内・利用できる特典・特典を探すの3タブ切り替え（初期表示はルート案内。利用できる特典はログイン時のみデータを取得）
- **現在地ボタン**: GPS位置取得・表示
- **店舗マーカー表示切替**: 地図右上に固定配置されるコントロールパネル

**マップ上コントロール（右上固定エリア）**:

| 要素 | 説明 |
|-----|------|
| アイコン | 商店アイコン（`pi pi-shop`） |
| ラベル | 「店舗」 |
| トグルスイッチ | ON/OFF で店舗特典マーカーを表示/非表示 |

- ON: 座標を持つ店舗特典（カテゴリ: BS001）を全件取得しマーカー表示
- OFF: 全ての店舗マーカーを削除
- マーカークリック: ポップアップ表示（特典名・内容・電話番号・住所・詳細URL）
- 検索連動: 特典検索結果に座標付き特典がある場合、検索結果のマーカーを地図に表示し、特典カードクリックで地図をパン＋ポップアップ表示

**特典を探すタブ（AppSearchBenefit）**:
- 検索条件: フリーワード、カテゴリ、居住地域、運転免許の所持状況、年齢、現在地からの距離（スライダー 0〜10km、0は「距離指定なし」。指定時は現在地を取得して検索）
- クリアボタン・検索ボタン
- 特典カード: 特典名・内容・対象条件、「詳細を見る」リンク、最終確認日（半年以上前は警告色、未設定時は「未確認」）
- 「情報を報告」ボタン: 確認ダイアログの後、特典情報の誤りを報告（Slack通知）
- 「URLをコピー」ボタン: 特典共有URL（`/?benefitId={id}`）をクリップボードにコピー

**特典共有URL**:
- `/?benefitId={id}` で開くと該当特典を取得し、「特典を探す」タブの上部に「シェアされた特典」として表示する（ログイン不要）
- 共有表示をクリアすると URL から `benefitId` を除去する

**レスポンシブ対応**:
- **デスクトップ**: 地図とサイドバーの左右分割表示
- **スマートフォン**: 地図メイン、サイドバーはスライドアップ

**画面要素**:

### S012: 会員登録画面（SignupPage.vue）

**概要**: 新規ユーザーアカウントを作成する画面。

**画面要素**:
- **ユーザー名入力**（必須）: 3〜30文字・半角英数字/ハイフン/アンダースコア・一意
- **パスワード入力**（必須）: 8〜64文字
- **パスワード確認入力**（必須）
- **メールアドレス入力**（必須）: 一意
- **居住地域**（必須）: 熊本県内市町村の選択
- **生年月日**（必須）: 日付選択
- **運転免許の所持状況**（必須）: 所持していない・所持している・返納・失効・停止・その他
- **運転免許返納日**（任意）: 日付選択
- **新規登録ボタン**: 登録実行（成功後はログイン画面へ遷移）
- **ログインリンク**: 「すでにアカウントをお持ちの方はこちら」→ ログイン画面（S011）

**バリデーション**:
- 必須項目チェック（ユーザー名・パスワード・パスワード確認・メールアドレス・居住地域・生年月日・運転免許の所持状況）
- パスワードと確認用パスワードの一致チェック
- ユーザー名・メールアドレス重複チェック（サーバー側）
- パスワード文字数チェック
- メールアドレス形式チェック
- 生年月日の未来日チェック

**URL**: `/reset-password?token=<リセットトークン>`

**画面要素**:
- **新しいパスワード入力**: 新パスワードフィールド
- **新しいパスワード（確認）入力**: 確認用フィールド
- **変更ボタン**: パスワードリセット実行

**バリデーション**:

**挙動**:
- URL にトークンがない場合はパスワードリセット要求画面（S015）へ遷移する

## 画面間連携

### 認証フロー
1. 未認証ユーザーはゲストとしてホーム画面にアクセス可能
2. プロフィール設定・パスワード変更機能はログイン必須
3. ログイン画面から認証後、元の画面に戻る（`redirect` クエリパラメータ）
4. セッション切れ時は自動的にログイン画面に遷移

### パスワードリセットフロー
1. ログイン画面から「パスワードを忘れた方はこちら」リンクをクリック
2. メールアドレスを入力してリセットメールを送信
3. メール内のURLをクリックしてリセット画面に遷移
4. 新パスワードを設定してログイン画面に遷移

### 検索フロー
1. ホーム画面で検索条件を入力
2. 地図上にマーカー表示、サイドバーに結果表示
3. マーカーまたはリストアイテムクリックで情報確認

### 特典共有フロー
1. 特典カードの「URLをコピー」で `/?benefitId={id}` をコピー
2. URLを受け取った人（ログイン不要）が開くと、ホーム画面の「特典を探す」タブに該当特典が「シェアされた特典」として表示される
3. 共有表示をクリアすると URL から `benefitId` が除去される

### 管理者フロー
1. 管理者でログインするとヘッダーに「管理者画面」メニューが表示される（遷移先: `/admin/benefits`）
2. 管理画面内はサイドバーで相互に遷移する
3. 未ログイン時は `/login?redirect=...`、管理者以外は `/` にリダイレクトされる

### 退会フロー
1. プロフィール画面の「退会する」リンクをクリック（管理者アカウントには非表示）
2. ダイアログでパスワードを入力して退会を確定
3. 退会後はホーム画面（`/`）に遷移する
