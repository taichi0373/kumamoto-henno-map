# 機能一覧

本システムで提供する全機能の一覧と詳細仕様を記載します。

## システム利用フロー

```mermaid
sequenceDiagram
    participant U as ユーザー
    participant M as 地図画面
    participant S as 検索機能
    participant R as 経路案内

    U->>M: アプリケーション起動
    M->>U: 熊本県地図を表示
    U->>M: 現在地取得を許可
    M->>U: 現在地を地図上に表示

    U->>S: 特典を検索
    S->>M: 検索結果をマーカー表示

    U->>R: 経路案内を要求
    R->>U: 公共交通機関の経路を表示

    Note over U,R: GTFSデータによる<br/>経路案内
```

## 機能別詳細仕様

### F001: 地図表示

**概要**: 熊本県全域の地図を表示し、特典提供施設をマーカーで表示する基本機能

**詳細仕様**:
- **地図エンジン**: MapLibre GL JS
- **地図データ**: OpenStreetMap
- **地図タイル**: `tile.openstreetmap.jp`（osm-bright-ja スタイル）
- **初期表示**: 熊本市中心部（経度 130.741584, 緯度 32.7898）、ズームレベル14
- **表示可能範囲**: 熊本県周辺に制限（経度 128.52-132.33, 緯度 30.90-34.06）
- **ズームレベル**: 8-18（県全域～建物レベル）
- **マーカー表示**: 特典カテゴリ別アイコン
- **店舗マーカー表示切替**: 地図右上のトグルスイッチ（`pi pi-shop` アイコン + 「店舗」ラベル）で、座標を持つ店舗特典（カテゴリ: BS001）のマーカー表示/非表示を切り替え可能
  - ON: `GET /benefit/markers` で座標付き店舗特典を全件取得しマーカー表示
  - OFF: 全ての店舗マーカーを削除
  - マーカークリック時: ポップアップで特典名・内容・電話番号・住所・詳細URLを表示
  - 検索結果との連動: 特典検索で座標付き結果がある場合、検索結果のマーカーを地図に表示
- **レスポンシブ対応**: スマートフォン・タブレット・PC対応

**入力**: なし
**出力**: 地図画面、特典マーカー
**前提条件**: インターネット接続
**例外処理**: 位置情報取得失敗時は初期表示位置（熊本市中心部）のまま表示

### F011: キーワード検索

**概要**: 特典名・特典内容によるフリーワード検索機能（「特典を探す」タブ）

**詳細仕様**:
- **検索対象フィールド**: 特典名、特典内容
- **検索方式**: 部分一致（LIKE検索）
- **他の検索条件との組み合わせ**: カテゴリ（F012）、居住地域（F013）、年齢・運転免許の所持状況（F014）、現在地からの距離（F015）とAND条件で組み合わせ可能
- **検索結果**: 件数上限なし。カテゴリごとにグループ化して表示
- **API**: `POST /benefit/search`

**入力**: 検索キーワード（文字列・任意）
**出力**: 検索結果リスト
**前提条件**: なし（全条件未入力の場合は全特典を返す）
**例外処理**: 結果が0件の場合は「条件に一致する特典がありません」メッセージ表示

### F046: ログイン試行制限

**概要**: 短時間に連続してログインに失敗した場合、アカウントを一時的にロックし不正アクセスを防止する機能

**詳細仕様**:
- **実装クラス**: `LoginAttemptService`（Caffeineキャッシュによるメモリ内管理）
- **ログイン失敗制限**: 10回連続失敗で15分間ロック
- **新規登録制限**: 5回試行で60分間ロック
- **パスワードリセット制限**: リセット要求・リセット実行それぞれ5回試行で15分間ロック
- **退会時のパスワード照合制限**: 5回失敗で15分間ロック（ユーザー単位）
- **ロック中の挙動**: ロック状態への試行は即時拒否（HTTP 429）
- **自動解除**: ロック時間経過後に自動解除
- **実装上の注意**: 単一インスタンス前提。水平スケーリング時はRedis等の共有ストアへの移行が必要

**入力**: なし（F042 ログイン・F041 会員登録・F045 パスワードリセット・F047 退会に透過的に組み込み）
**出力**: ロック中は HTTP 429 レスポンス
**前提条件**: F042（ログイン・ログアウト）機能の一部
**例外処理**: ロック判定はサーバーサイドで実施

### F061: フィードバック送信

**概要**: ホーム画面のサイドバー下部にある「問い合わせ」ボタンからモーダルダイアログを開き、バグ報告・要望・その他のカテゴリで意見を送信する機能

**詳細仕様**:
- **アクセス**: ホーム画面のサイドバー下部「問い合わせ」ボタン（`pi pi-envelope` アイコン）
- **認証**: 不要（未ログインユーザーも送信可）
- **入力項目**:
  - カテゴリ（必須）: バグ報告 / 要望 / その他
  - お名前（任意）: ログイン済みの場合はユーザー名を初期値として自動入力
  - メールアドレス（任意）: ログイン済みの場合はメールアドレスを初期値として自動入力
  - 内容（必須）: 最大2000文字（お名前は最大100文字、メールアドレスは最大255文字。文字数上限は画面側で制御）
- **送信先**: バックエンド経由でSlack Incoming Webhookに通知
- **Slack通知フォーマット**: カテゴリ・お名前・メールアドレス・内容・送信日時・ユーザー情報（ログイン済み/未ログイン）を含む
- **Webhook URL未設定時**: Slack送信をスキップしてサーバーログにのみ出力（サイレント処理）

**入力**: カテゴリ、お名前（任意）、メールアドレス（任意）、内容
**出力**: 送信完了メッセージ（モーダル内）
**前提条件**: 内容フィールドに1文字以上の入力
**例外処理**: サーバーエラー時はモーダル内にエラーメッセージを表示（Slack送信自体の失敗はサーバーログのみ出力し、送信完了扱い）

**入力**: なし
**出力**: モーダルダイアログ（スクロール可能）
**前提条件**: なし

### F031: 公共交通経路探索

**概要**: GTFSデータを活用した公共交通機関での経路案内

**詳細仕様**:
- **連携システム**: OpenTripPlanner 2.5.0
- **対応交通手段**: 公共交通機関、電車、バス、徒歩、自転車（選択式）
- **出発地・目的地の入力**: 地名検索（Nominatim）による候補選択、または現在地ボタンによる現在地の設定
- **時刻指定**: 出発時刻指定・到着時刻指定を切り替え可能（日付・時刻は任意）
- **経路候補**: 到着時刻の早い順に最大3件
- **結果表示**: 地図上の経路線、出発・到着時刻、所要時間、運賃（割引後運賃）、乗り換え回数、区間ごとの詳細、リアルタイムの遅延情報
- **更新頻度**: GTFSデータは毎週有効期限をチェックし、必要に応じて自動更新
- **API**: `POST /route/search`

**入力**: 交通手段、出発地、目的地、出発/到着、日付、時刻
**出力**: 経路候補リスト
**前提条件**: 有効な出発地・目的地の指定
**例外処理**: 経路が見つからない場合は「経路が見つかりませんでした」メッセージを表示

**概要**: 特典カードの「情報を報告」ボタンから、特典情報の誤り（情報が古い等）を管理者に報告する機能

**詳細仕様**:
- **アクセス**: 「特典を探す」タブ・「利用できる特典」タブの特典カードにある「情報を報告」ボタン
- **認証**: 不要
- **操作**: 確認ダイアログで報告を確定
- **送信先**: バックエンド経由でSlack Incoming Webhookに通知（特典名・特典ID・報告日時）
- **API**: `POST /benefit/{benefitId}/report`

**入力**: 特典ID
**出力**: 送信完了メッセージ
**前提条件**: 報告対象の特典が存在すること
**例外処理**: 送信失敗時はエラーメッセージを表示
