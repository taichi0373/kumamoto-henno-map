【採番開始ID】
※ 以下の [採番開始ID] を実際のIDに書き換えてから使用してください。

  交通系（バス・タクシー・電車・ICカード・商品券等）の開始ID: BEN-[採番開始ID]

■ 出力形式

各特典について以下のSQL INSERT文を出力してください。
特典が複数ある場合はすべて出力してください。

INSERT INTO BENEFIT VALUES (
  'BENEFIT_ID',        -- BEN-000001 形式（6桁ゼロ埋め）
  'MUNICIPALITY_CD',   -- 下記の自治体コード表を参照
  'CATEGORY_CD',       -- 下記のカテゴリコード表を参照
  'BENEFIT_NAME',      -- 特典の正式名称（最大400文字）
  'BENEFIT_SHORT_NAME',-- 表示用の短縮名称（最大200文字）
  'BENEFIT_DETAIL',    -- 割引内容・条件の詳細（最大1000文字）
  'EXP_DETAIL',        -- 有効期限（不明・期限なしの場合は空文字 ''）
  'PHONE_NUMBER',      -- 問い合わせ先電話番号（なければ ''）
  'BENEFIT_URL',       -- 公式URL（なければ ''）
  ADDRESS,             -- 店舗住所がある場合は '住所文字列'、なければ NULL
  NULL,                -- LATITUDE（常にNULLで出力）
  NULL,                -- LONGITUDE（常にNULLで出力）
  CURRENT_TIMESTAMP,
  CURRENT_TIMESTAMP
);

■ 注意事項

- 情報が不明・記載なしの場合は '' （空文字）を使用してください（NULLではなく）
- 住所（ADDRESS）だけは情報がない場合 NULL を使用してください
- LATITUDE・LONGITUDEは常に NULL で出力してください
- テキストに自治体名が書かれていて、上記の自治体コード表にない場合は
  最も近い上位自治体（例: 不明な村→所属郡→熊本県「43」）を使用してください
- BENEFIT_NAMEに特典名が明確でない場合は「事業者名 + 特典種別」を使用してください
